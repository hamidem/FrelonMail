Comment récupérer le fichier du message ?
Gmail

Ouvrez le message, choisissez Plus ⋮, puis Télécharger le message.

Gmail fournit un fichier EML.
Outlook

Ouvrez le message, puis choisissez Autres actions et Enregistrer sous ou Télécharger.

Outlook fournit généralement un fichier MSG, directement pris en charge par Frelon.
Thunderbird

Faites un clic droit sur le message, choisissez Enregistrer sous, puis le format courrier EML.

Le raccourci Ctrl + S est également disponible.

Important : enregistrez le message lui-même, pas l'une de ses pièces jointes. Frelon n'ouvre aucun contenu actif.
